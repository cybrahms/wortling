Banality is a rejection criterion. A short, unambiguous span is still not worth a
review slot when it teaches nothing about the word:
- drop bare template sentences mined from a form or application ("Ich möchte ein
  Auto umschreiben", "Hiermit beantrage ich ...") - they name a procedure, not a
  sense in use;
- drop shop, invoice and interface boilerplate ("Bezahlung per PayPal - einfach,
  schnell und sicher.", "Ihre Daten werden verschlüsselt übertragen.");
- drop a span where the target is the only content word, so the meaning has to be
  guessed from outside the sentence.

content words of context. When you drop for one of these reasons, say which in the
reason - "bare form template", "shop boilerplate", "target is the only content
word" - so the report distinguishes a banal card from one that failed on level.
